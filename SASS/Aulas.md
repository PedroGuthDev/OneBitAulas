# Aula 1. Conhecendo o Sass

## O que é o Sass?

A sigla significa Syntactically Awesome Style Sheets. É uma linguagem de extensão do CSS, premite escrever folhas de estilo com recursos avançados que não existem na linguagem css convencional.
O código Sass não funciona no navegador, ele precisa ser compilado para CSS puro.

### As 2 variações de sintaxe do Sass

1. Aqruivos .sass: era a sintaxe original, baseada em indentação, sem chaves e sem ponto e vírgula.
2. Arquivos .scss: é a sintaxe atual, baseada em chaves e ponto e vírgula, como o CSS convencional.

Ambas podem ser usadas e suportam todos os recursos do Sass, ficando a critério do programador.

### Recursos mais usados do Sass

1. Variáveis.
2. Aninhamento.
3. Funções, Mixins e outras "At-Rules" (regras que começam com @).
4. Importação de módulos/arquivos.
5. Módulos nativos (com funções para manipulação de cores, textos, etc).
