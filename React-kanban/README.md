---

## 🚀 Sobre

Este projeto é um pequeno site para gerenciar tarefas, permitindo:

- Adicionar tarefas
- Alterar o estado e prioridade das tarefas
- Editar tarefas
- Visualizar tarefas
- Deletar tarefas

**Foco principal:** prática de CRUD com API simulada + TypeScript e React no frontend.

## 🧰 Tecnologias Utilizadas

| Tecnologia      | Uso                                        |

| **TypeScript**  | Superset JavaScript para tipagem estática  |
| **Vite**        | Ferramenta de build rápida para o frontend |
| **JSON Server** | API simulada local                         |
| **Radix UI**    | Componentes de UI acessíveis               |

## 📌 Como Usar

Clone o repositório:

```bash
git clone https://github.com/PedroGuthDev/React-kanban.git
```

Instale as dependências:

```bash
npm install
```

Crie um arquivo .env na raiz do projeto e adicione a seguinte linha:

```bash
VITE_API_URL=http://localhost:3000
```

Inicie a API local:

```bash
npm run json-server
```

Inicie o frontend:

```bash
npm run dev
```

Abra o localhost:5173 no navegador.
